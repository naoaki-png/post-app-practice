# ユースケース記述（お客さま側）

#### UC-07:お客様が支払いをする

- **アクター**: お客様
- **事前条件**: お客様はログインした状態。注文は完了している。
- **基本フロー**:
    1. お客様が注文画面で「注文」ボタンを押す。
    2. システムが注文画面から算出し、支払い画面を表示する。
    3. お客様は金額が間違いないか確認し、「支払いボタン」を押す。
    4. システムがクレジットカードの入力画面を表示する。
    5. お客様がクレジットカード情報を入力し、「確定」ボタンを押す。
    6. システムが支払いを完了させ、注文確認画面を表示する。
- **代替フロー**:
    - 5a.クレジット番号入力に誤りがあった際:クレジット情報が間違っています。
- **事後条件**: 注文が確定され、注文確認画面に1件表示される。
- **受け入れ条件**:
    - [ ] 注文すると、注文確認画面に注文履歴が表示される。
