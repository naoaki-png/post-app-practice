# ユースケース記述（店員側）

#### UC-09:店員が注文履歴を確認する

- **アクター**: 店員
- **事前条件**: なし
- **基本フロー**:
    1. 店員が注文履歴画面で「注文詳細」ボタンを押す。
    2. システムが注文詳細画面を表示する。
    3. 店員は注文に応じて商品を提供し、「提供済み」ボタンを押す。
    4. システムが提供済みフラグを立て、注文履歴画面を表示する。
- **代替フロー**:
    - 3a.間違えて提供済みボタンを押してしまった場合:注文一覧画面から履歴を削除できる。
- **事後条件**: 提供済みフラグを立てて、注文履歴画面では非表示となる。
- **受け入れ条件**:
    - [ ] 注文履歴画面では処理した注文が非表示となっているか。
