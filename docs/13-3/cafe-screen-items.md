# メニュー画面 画面項目定義

| 項目名             | 種類   | 必須 | 内容                                                                                         |
| :----------------- | :----- | :--- | :------------------------------------------------------------------------------------------- |
| 画面見出し         | 表示   | -    | 「メニュー」                                                                                 |
| 商品名             | 表示   | -    | 商品名を表示する                                                                             |
| 価格               | 表示   | -    | 1つの商品価格を表示する                                                                      |
| 商品説明           | 表示   | -    | 商品の説明書きを表示する                                                                     |
| 注文個数           | 選択   | -    | その商品を何個注文するか個数を選択する。売り切れている場合は選択不可                         |
| 買い物かごへ入れる | 選択   | -    | 買い物かごに選択した個数がストックされる                                                     |
| 注文する           | リンク | -    | 商品注文画面に遷移。買い物かごにストックされた商品が注文画面に表示され、合計金額が表示される |
