# エンドポイント一覧

|   ID   | メソッド |   エンドポイント   |           何をするか            | 認証 |
| :----: | :------: | :----------------: | :-----------------------------: | :--: |
| API-01 |   GET    |     /api/posts     |     投稿一覧画面を取得する      | 必要 |

# エンドポイント詳細

#### API-03: 登録した投稿を訂正する

- **メソッドとエンドポイント**: PUT /posts/{post}
- **認証**: 必要
- **送るもの**: タイトル、カテゴリ、本文
- **返すもの（うまくいったとき）**: 201。訂正した投稿1件（タイトル、カテゴリ、本文）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）／422（送ったものに不備があるとき）／404（その投稿が見つからないとき）

# エラーレスポンス一覧

| 起きること                           | ステータス | 返すもの                           |
| :----------------------------------- | :--------- | :--------------------------------- |
| ログインしていない                   | 401        | ログインが必要である旨の文言       |
| その投稿を操作してよい相手ではない   | 403        | 権限が無い旨の文言                 |
| 指定した投稿が見つからない           | 404        | 見つからない旨の文言               |
| 送ったものに不備がある（登録・訂正） | 422        | 不備のあった項目と、その理由の文言 |
